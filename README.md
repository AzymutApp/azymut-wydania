# Azymut

Aplikacja na Androida, która pomaga uporządkować telefon: zawiesza wybrane rodzaje aplikacji, włącza bezpieczne wyszukiwanie w przeglądarkach i pilnuje, żeby te ustawienia zostały na miejscu.

To repozytorium zawiera tylko pliki instalacyjne (APK). Azymut powstał na podstawie aplikacji [Déchaîner](https://github.com/warleysr/dechainer) (licencja Apache-2.0).

## Pobieranie

Pliki są w zakładce [Releases](https://github.com/AzymutApp/azymut-wydania/releases): plik `azymut-<numer>.apk`. Wydania oznaczone „Pre-release” są próbne, przeznaczone do testów.

Zainstalowana aplikacja sama sprawdza raz dziennie, czy jest nowsza wersja, i aktualizuje się.

## Instalacja

1. Pobrać plik APK na telefonie.
2. Otworzyć pobrany plik i zezwolić na instalację z tego źródła.
3. Otworzyć Azymut i przejść kreator aktywacji (około 10 minut, potrzebne Wi‑Fi, komputer nie jest potrzebny).

Wymagania: Android 11 lub nowszy.

## Ważne przed instalacją

Po aktywacji Azymut działa jako administrator urządzenia (Device Owner). Zmiana ustawień i wyłączenie Azymutu wymagają kodu odzyskiwania ustalonego przy instalacji. Bez kodu jedyną drogą jest przywrócenie ustawień fabrycznych, które usuwa wszystkie dane z telefonu.
